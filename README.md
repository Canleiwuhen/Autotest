样本中心造数工具使用说明
前端访问地址：http://10.227.4.150：8086
操作步骤：
1、选择要造数据的场景：
主流程测试场景1：1.MYBGI录入送检单-2.MYBGI物流寄送-3.包裹接收-4.医学拆包-5.新增容器-6.医学到样定位（新）-7.出库申请-8.出库审核-9.入库申请-10.入库审核
主流程测试场景2：1.包裹补录-2.医学拆包
主流程测试场景3：1.MYBGI录入送检单-2.MYBGI物流寄送-3.包裹接收-4.医学拆包-5.新增容器-6.医学到样定位（新））-7.出库申请-8.出库审核-9.接收确认
主流程测试场景4：1.MYBGI录入送检单-2.MYBGI物流寄送-3.包裹接收-4.医学拆包-5.新增容器-6.医学到样定位（新）-7.医学信息审核
主流程测试场景5：1.MYBGI录入送检单-2.MYBGI物流寄送-3.包裹接收-4.医学拆包-5.样本批量接收
2、填写需要执行的步骤（需要造到哪一步的数据）：根据场景的路径的实际长度填写
3、填写需要执行造数的次数：例如只跑一次就填1
4、执行账号：造数时使用的账号
5、点击执行：开始造数，造数完成后下方展示造数过程中生成的关键信息，包括样本编号、物流单号、出库申请单号、入库申请单号......
不支持的功能：
1、一次执行，批量造样本数据
2、不支持中间造数
